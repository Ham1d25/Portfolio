# Personal Portfolio

A clean, responsive personal portfolio website built with HTML, CSS, and JavaScript. Features dynamic theme switching and social media integration.

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to desktop, tablet, and mobile displays.
- **Dark / Light Theme Toggle**: Switch between light and dark visual modes dynamically.
- **Social Media Links**: Quick access to Discord, Facebook, GitHub, and Instagram profiles.
- **Project Showcase**: Visual project previews and custom assets.

## 🛠️ Tech Stack

- **HTML5** - Page structure and semantic markup
- **CSS3** - Custom styling, layout design, and theme variables
- **JavaScript (ES6+)** - Interactivity and theme switching logic
